It's been 2 weeks since my first post. Not much has actually changed on the frontend since then. I added a privacy page and notification bar, since I plan to use cookies for persisting data on the client-side for some cool applications.

Most of the stuff has been on the backend. I'm learning to implement a realtime chat using Django Channels and websockets. If there was no Channels, I would probably have tried to use a nodejs server of some sort. There's a lot of pros to using a full javascript stack, but I'm planning to make some Python applications and it would be easier to implement them if the backend is also Python. I'm also going to replace this basic blog backend system with Django CMS (or another django CMS plugin). Hopefully this will all be ready by the next blog post (2 weeks from now).

Well that's all for now.
