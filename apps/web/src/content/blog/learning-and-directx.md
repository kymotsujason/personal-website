Still working on the real time chat. I'll probably drop some features due to the errors that they cause (still getting the hang of debugging Django). The framework is pretty much there, I just need to fix the errors really.

It should be pretty easy to hook into the Twitch API and display the text on screen, with a maximum amount of lines shown. I'm debating whether or not to add a way for the streamer to input text straight into the overlay. This isn't hard, but the way I'm doing it might make it interfere with the game. Well, there's only so much UX can do to idiotproof (no offense) these kinds of things.
